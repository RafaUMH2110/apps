¿Cómo funciona GenOutFit Pro?

GenOutFit es una aplicación de un solo archivo HTML pensada para diseñadores de moda: a partir de la fotografía de una prenda, usa IA para identificar sus características y proponer un outfit completo de prendas afines, y genera una imagen de cada pieza con FLUX (fal.ai). Esta versión Pro añade caché de resultados, caché de prompts de Anthropic, un catálogo de modelos ampliado y un modo por lotes para procesar varias prendas de una sola vez.

  1. Subes (o arrastras) la foto de una prenda.
  2. Eliges cuántas piezas debe tener el outfit completo y si quieres además una imagen de un/a modelo vistiendo todo el conjunto.
  3. La IA (Claude, GPT o Gemini, a tu elección) analiza la foto y devuelve una descripción breve y un prompt en español, listo para FLUX, de cada pieza del outfit.
  4. Puedes revisar y editar cada prompt antes de continuar.
  5. Al pulsar "Continuar", GenOutFit genera con FLUX una imagen PNG de cada pieza y, si la pediste, la foto del modelo: esta última se compone con FLUX Kontext a partir de la prenda original y de las imágenes de las piezas ya generadas, para que el modelo lleve exactamente esas prendas y complementos.
  6. Puedes descargar cada imagen por separado o exportarlas todas juntas en un PDF.

Novedades Pro:

  • Caché de resultados: antes de generar, comprueba si ya existe en el historial de este navegador una generación con la misma imagen de prenda y los mismos parámetros; si la hay, la recupera al instante sin gastar nada. Se puede desactivar o vaciar desde el panel "Pro" de arriba.
  • Caché de prompts de Anthropic: con proveedor Anthropic, marca las instrucciones del sistema con cache_control para abaratar llamadas consecutivas con el mismo bloque.
  • Modo por lotes: sube varias prendas a la vez; cada una genera su propio outfit completo, de principio a fin y sin pausa de revisión, con una lista de progreso y descarga conjunta en ZIP o un PDF por outfit.
  • Catálogo de modelos ampliado: incluye las variantes más recientes de Claude, GPT y Gemini.

Avisos frecuentes: error 401/403 → la clave no es válida o no tiene permisos. Error 429 → límite de uso alcanzado, espera e inténtalo de nuevo. Error 404 → el modelo no existe o no está disponible en tu cuenta. "La respuesta no tiene el formato esperado" → GenOutFit reintenta automáticamente una vez; si persiste, prueba con otro modelo o una foto más clara de la prenda.

Pro — modo de trabajo, caché y lotes

Antes de llamar a la IA o a FLUX, se comprueba si ya existe en el historial de este navegador una generación con la misma imagen de prenda y los mismos parámetros (proveedor, modelo, nº de piezas, modelo incluido o no, pasos, tolerancia e instrucciones del sistema). Si la hay, se recupera al instante, sin gastar nada.

Marca el bloque de instrucciones del sistema como reutilizable entre llamadas consecutivas a Anthropic, abaratando las siguientes mientras no lo cambies. Solo hay ahorro real si el bloque supera el mínimo cacheable del modelo activo.

Cuántas prendas afines debe proponer la IA, además de la que has subido. Como no vas a incluir la foto del modelo, el máximo es 4.

Más pasos = más detalle pero más lento y más caro en fal.ai.

1 bloquea más contenido sensible; 6 es el más permisivo. Define el parámetro safety_tolerance de fal.ai.

Esta foto no se genera solo a partir de texto: se compone con FLUX Kontext a partir de la prenda original y de las imágenes de cada pieza ya generadas, usándolas como referencia, para que el modelo lleve EXACTAMENTE esas prendas y complementos. Si la incluyes, el máximo de piezas pasa a 3, para que la prenda original más las piezas nunca supere las 4 imágenes de referencia que admite fal.ai por llamada y la foto del modelo se genere siempre en una sola llamada.

Rol que sigue la IA al analizar la prenda y redactar los prompts. Puedes editarlo; por defecto es el definido para esta app.

La estimación consulta solo el conteo de tokens de ENTRADA (gratuito en los proveedores que lo ofrecen) con el mismo texto/imagen que se enviaría; los tokens de SALIDA nunca se pueden conocer antes de generar, solo se puede mostrar el techo configurado.

Cada prenda del lote se procesa de principio a fin (análisis + imágenes) una detrás de otra, para no saturar los límites de tasa del proveedor ni de fal.ai.
