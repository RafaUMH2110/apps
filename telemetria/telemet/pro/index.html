Glosario

Station IDEl identificador de tu estación en wunderground.com (My Profile → My Devices).
API KeyClave opcional que algunas cuentas de Weather Underground exigen para leer datos. Se envía como parámetro de la URL, nunca como cabecera.
FreshnessSegundos transcurridos entre el instante en que la estación registró la lectura y el instante actual. Si supera el umbral configurado, la lectura se marca como obsoleta ("stale").
Tendencia (▲ ▼ —)Compara el último valor de cada variable con el anterior: sube, baja o se mantiene estable.
BackoffEspera creciente entre reintentos tras un error transitorio (red, tiempo límite, 5xx): se duplica cada vez, hasta un máximo configurable.
Comprobación de plausibilidadCada lectura se compara con un rango físicamente posible por variable; si algo se sale de rango, se avisa antes de confiar en el dato.
Eje X de los minigráficos«Por lectura» espacia los puntos de forma uniforme; «Por tiempo real» los sitúa dentro de una ventana fija (nº de puntos × intervalo de sondeo) terminada ahora mismo, con la hora de inicio y fin de esa ventana bajo el gráfico, agrupados a la derecha si el histórico no está lleno y con huecos visibles si hubo reintentos.
