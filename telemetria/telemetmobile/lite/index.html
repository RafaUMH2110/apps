TeleMet Mobile Lite

Versión reducida de TeleMet Mobile: muestra solo las condiciones actuales (temperatura, humedad, viento y lluvia) de tu estación meteorológica personal, consultando la API de Weather Underground / Earth Network directamente desde el navegador. Sin gráficas ni histórico.

Sin backend propio: el Station ID y la API Key se guardan solo en este dispositivo. Para instalarla en la pantalla de inicio del iPhone: botón Compartir de Safari → "Añadir a pantalla de inicio".

  • Luz de estadoVerde: en vivo. Ámbar: error transitorio. Rojo: error fatal (Station ID o API Key inválidos). Gris: modo manual en espera, o detenido.
  • Modo automáticoVuelve a consultar la estación sola, cada el número de minutos que indiques (de 1 a 10).
  • Modo manualNo se actualiza sola: pulsa el botón de actualizar (↻) cuando quieras ver el dato más reciente.
