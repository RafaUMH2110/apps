    TeleMet Mobile Pro

    Versión Pro de TeleMet Mobile: muestra en un panel estilo app nativa las condiciones actuales y la evolución del día de tu estación meteorológica personal, consultando la API de Weather Underground / Earth Network directamente desde el navegador.

    Sin backend propio: el Station ID y la API Key se guardan solo en este dispositivo, y el histórico de cada día se persiste en este navegador (IndexedDB). Para instalarla en la pantalla de inicio del iPhone: botón Compartir de Safari → "Añadir a pantalla de inicio".

    • Luz de estadoVerde: en vivo. Ámbar: reintentando o dato obsoleto. Rojo: error fatal (Station ID o API Key inválidos). Gris: pausado o detenido.
    • Tendencia (▲ ▼ —)Compara la última lectura de temperatura, humedad, presión, viento y racha con la anterior: sube, baja o se mantiene estable.
    • Sensación térmicaTemperatura percibida, calculada a partir de la temperatura, la humedad y el viento (índice de calor con calor húmedo, sensación de frío con viento y temperaturas bajas). Solo se muestra cuando difiere de la temperatura real.
    • Punto de rocíoTemperatura a la que el aire se satura y condensa en forma de rocío. Cuanto más cerca está de la temperatura actual, más bochornoso se percibe el ambiente.
    • Resumen del díaMáxima y mínima de temperatura, lluvia acumulada, racha máxima y hora de la última lectura, de un vistazo.
    • Últimos díasResumen diario (máxima, mínima, lluvia y racha) de hasta 7 días, a partir de lo acumulado en este dispositivo.
    • Obsoleto trasSegundos desde la última lectura a partir de los cuales se considera que el dato ya no es fiable.
    • BackoffEspera creciente entre reintentos tras un error transitorio: se duplica cada vez, hasta el máximo configurado.
    • Histórico del díaAl abrir la app se intenta recuperar el día completo desde la API; si tu cuenta no tiene acceso, se sigue solo con lo sondeado en este dispositivo.
