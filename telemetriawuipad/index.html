    TelemetriaWU iPad

    Séptima app de la serie TelemetriaWU. Muestra en un panel de dos paneles, pensado para el ancho de un iPad, las condiciones actuales y la evolución del día de tu estación meteorológica personal, consultando la API de Weather Underground / Earth Network directamente desde el navegador.

    Sin backend propio: el Station ID y la API Key se guardan solo en este dispositivo, y el histórico de cada día se persiste en este navegador (IndexedDB). Para instalarla en la pantalla de inicio del iPad: botón Compartir de Safari → "Añadir a pantalla de inicio".
